# md抓马 (MD-Drama)

> 智能网页内容深度抓取与排版 Chrome 插件，专为 Obsidian 打造。

## 🌟 核心特性
- **智能懒加载探测**：自动识别容器滚动与动态 DOM，适配飞书文档、生财有术、微信公众号等复杂懒加载界面。
- **高质量 Markdown 排版**：公式（LaTeX）、表格、代码块高亮、Callout 块、标准 Markdown / Frontmatter 完美转换。
- **图片与多媒体本地化**：绕过防盗链，支持下载原图并自动映射为 Obsidian 附件路径与双链。
- **Obsidian 直连同步**：支持 Local REST API / Advanced URI / 本地目录导出。
