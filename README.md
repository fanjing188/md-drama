# MD抓吗 (MD-Drama) - 完整功能与架构技术手册

> 专为高效知识管理打造的 Chrome 智能网页深度剪藏与 Obsidian 直连扩展（Manifest V3）。

---

## 🌟 核心特性全览

### 1. 👾 可爱文档像素风 (Cute Pixel Art Document Aesthetic)
* **复古像素视觉体系**：复古奶油底（`#FFFDF8`）+ 纯黑实体像素边框（`2px solid #2D2721`）+ 经典实体像素投影（`3px 3px 0 #2D2721`）；
* **全新专属 Logo**：描绘一只强力抓取的可爱小手掌紧紧扣住带有经典 Markdown `M↓` 标识的白底文档；
* **极简单按钮交互**：弹出面板精简为单个醒目核心操作按键——**`⚡ 抓下来`**（快捷键 `Alt+Shift+S`）；
* **当前网页基础信息卡片**：自动识别并展示当前网站徽章（`👾 飞书文档` / `💬 微信公众号` / `💡 知乎` / `📚 语雀` / `💎 掘金` / `🌐 网页`）、页面完整标题与 Host 域名。

---

### 2. ✨ 网页划选像素风圈选与「抓下来」弹窗
* **像素风高亮圈选框**：在任意网页选中文本时，自动在选区周围绘制像素虚线描边框与 4 个像素角标，并配有 `[👾 已圈选]` 提示微标；
* **「抓下来」交互小按钮**：浮现于选区正上方，点击即可将所选内容抓取并归档；
* **灵活保存模式配置 (Selection Save Mode)**：
  * **模式 1：保存到指定目录下新文件**（默认独立文档存放）；
  * **模式 2：追加到指定现有文件末尾**（如 `03-知识库/网页剪藏/每日摘录.md` 或 `Inbox.md`），自动带上来源标题、直达链接与时间戳追加写入；
* **独立功能开关**：在设置后台可随时开启或关闭划选弹窗（`enableSelectionBubble`）。

---

### 3. 📜 抓取历史记录系统 (History System)
* **大容量滚动抽屉**：点击右上角 `[历史]` 即可展开专属历史面板，支持同时展示 10+ 条历史记录并流畅向下滚动；
* **完整元数据追溯**：记录抓取时间、成功/失败状态、抓取模式（整篇/选区/追加）、文档标题；
* **🌐 原网页直达跳转**：每条记录附带来源直达链接，点击即可在新标签页瞬间打开原文。

---

### 4. ⚙️ Tab 独立分类设置后台 (Sticky Header)
* **固定冻结顶部菜单栏**：无论页面如何滚动，顶部品牌与 4 大分类选项卡始终固定在顶部；
* **Tab 独立分类展示**：点击对应 Tab 仅展示对应内容（`✨ 页面划选`、`💾 Obsidian 直连`、`🧹 清洗去噪`、`🎨 排版与媒体`），配置体验优雅清晰。

---

### 5. 🚀 6 阶段通用解析流水线 (Pipeline Engine)
* **DOM 语义重塑 (Transformers)**：
  * **Mermaid 流程图还原**：识别原始图表数据，原生还原为 ````mermaid` 可编辑代码块；
  * **代码 Diff 对比还原**：识别差异行，还原为 ````diff` 语法（`+` / `-`）；
  * **KaTeX / MathJax 公式还原**：还原为行内 `$formula$` 与块级 `$$formula$$`；
  * **代码块行号与复制按钮清洗**：剥离行号干扰，提取语言标记输出标准 Fenced Code Block；
  * **Flex/Grid 伪表格重构**：探测无 `<table>` 的类表格布局，重构为标准 GFM 表格；
  * **CSS 背景图修复**：自动识别 `background-image: url(...)` 并转为标准 `<img>`；
  * **Shadow DOM 穿透**：递归穿透现代 Web Components 封装组件。
* **盘古排版 (Pangu Spacing)**：中英文与数字符号混排时自动注入舒适间距。
* **关键词自动双链注入**：根据预设词库（如 `Obsidian`, `SEO`, `出海`）自动生成 `[[WikiLinks]]`。

---

### 6. 🧹 深度内容清洗与去噪 (Content Cleaner)
* **DOM 层广告清洗**：自动移除广告容器、分享栏、点赞打赏、隐藏 DOM、二维码浮层；
* **引流话术过滤**：剔除“记得点赞关注在看”、“点击下方名片”、“一键三连”等营销套话；
* **格式规范化**：自动压缩连续多余空行、规范化列表标记（`- item`）与标题前后空行。

---

### 7. 🖼️ 资产本地化与图片防盗链直解
* **原位精准插入**：图片提取后注入独立段落排版（`\n\n![alt](attachments/xxx.png)\n\n`）；
* **飞书官方永久流地址直解**：从 `image-token` + `data-record-id` 构建永久 Drive Stream CDN 链接，彻底杜绝 blob 失效；
* **防盗链穿透与全量下载**：Background Service Worker 绕过 Referer 限制并发下载原图。

---

### 8. 💾 Obsidian 仓库直连与离线韧性
* **Obsidian Local REST API**：秒级后台静默写入 Markdown 文档与二进制图片；
* **智能域名分流 (Domain Routing)**：
  * `feishu.cn` $\rightarrow$ `03-知识库/工作文档/`
  * `shengcaiyoushu.com` / `zsxq.com` $\rightarrow$ `03-知识库/商业社群/`
  * `weixin.qq.com` $\rightarrow$ `03-知识库/公众号精选/`
  * `zhihu.com` $\rightarrow$ `03-知识库/知乎精选/`
* **离线草稿箱 (Sync Queue)**：离线时自动存入本地草稿池，支持恢复后重试补写。

## 🛠️ 项目目录结构

```text
md-drama/
├── manifest.json                 # Manifest V3 核心声明与快捷键配置
├── background/
│   └── service-worker.js         # 后台路由、快捷键监听、图片下载与 REST API 写入
├── content/
│   ├── index.js                  # 内容脚本入口与消息调度
│   ├── scroller.js               # 智能平滑滚动与懒加载探测器
│   ├── cleaner.js                # 废话词库与 DOM 噪声过滤器
│   ├── extractor.js              # 内容提取与 Markdown 转换协调器
│   ├── pipeline/
│   │   ├── transformers.js       # 复杂结构（Mermaid/Diff/KaTeX/伪表格）重塑器
│   │   └── parser-engine.js      # 6 阶段通用解析流水线引擎
│   ├── adapters/                 # 8 大知识平台专属适配器
│   └── ui/
│       ├── bubble.js             # 像素风划选高亮圈选框与「抓下来」按钮
│       └── bubble.css
├── utils/
│   ├── logger.js                 # 分级运行日志系统
│   └── sync-queue.js             # 离线草稿箱管理器
├── popup/
│   ├── popup.html                # 可爱像素风交互面板
│   ├── popup.css                 # 像素复古实体样式体系
│   └── popup.js                  # 交互逻辑、页面基础信息与历史记录抽屉
├── options/                      # Tab 独立分类设置后台与固定冻结顶栏
├── test/                         # 自动化单元测试套件
└── dist/
    └── md-drama-v1.3.0.zip       # 最新构建发布包
```
