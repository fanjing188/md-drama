第 1 步：Obsidian 存储与同步服务

配置抓取的 Markdown 文章与本地图片如何存入您的知识库

使用 REST API 需要在 Obsidian 的「第三方插件」中安装并启用 Local REST API 插件。
💡 推荐端口：填 27123（HTTP 协议标准端口），连接最稳定且无需信任自签名证书！
抓取的文章将自动存入 Obsidian 仓库的该目录下。
网页下载的图片将保存在该目录下，避免图片失效。
✨

第 2 步：网页划选圈选与剪藏模式

配置在浏览网页时用鼠标划选文字的高亮交互与保存规则

开启后，在任意网页划选文本，会自动出现像素虚线边框和快捷抓取按钮。
[👾 已圈选] “这是划选的一段文字，点击右侧按钮秒存笔记”
⚡ 抓下来
每次划选抓取时，将以时间戳和引用块格式自动追加到此文件末尾。
🧹

第 3 步：智能清洗去噪与排版规则

自动过滤网页营销广告、点赞浮层，规范化 Markdown 格式

🎉

第 4 步：配置清单确认与生效

已就绪！请确认您的偏好配置，点击保存即可开启极速剪藏

⚡ 全局静默抓取快捷键
Alt + Shift + S
同步模式: Obsidian REST API 直连
整页保存路径: 03-知识库/网页剪藏
划选保存模式: 保存为独立新文件
图片本地化: 全量下载至附件目录
智能去噪: 已开启 (过滤营销套话与广告)
✓
恭喜！配置已全部保存生效！

您现在可以在任意网页按下 Alt+Shift+S 或划选文本点击「⚡ 抓下来」进行剪藏啦！
